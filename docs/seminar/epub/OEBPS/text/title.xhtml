GPU 메모리 검증의 내부 구조

MemtestG80 코드로 읽는 CUDA 병렬 프로그래밍

원저작: Imran Haque, Stanford University (2009)

원본 코드: github.com/ihaque/memtestG80 · LGPL v3

이 책에 관하여. 이 전자책은 오픈소스 GPU 메모리 테스터 MemtestG80의 실제 소스 코드(memtestG80_core.cu 등)를 바탕으로, CUDA 병렬 프로그래밍의 핵심 원리를 코드와 함께 설명하는 한국어 기술 해설서입니다. 단순한 "쓰고 되읽기"라는 아이디어가 어떻게 수십만 스레드의 병렬성, 공유 메모리 리덕션, 비트 단위 오류 집계로 구현되는지를 따라갑니다.

키워드: GPU 메모리 테스트, CUDA, 병렬 리덕션, 메모리 병합(coalescing), 공유 메모리, __popc, ECC, 소프트 오류

이 해설서는 MemtestG80의 배경 논문이 저장소에 포함되어 있지 않아, 대응 자료인 자매 프로젝트 cuda_memtest의 SAAHPC'09 논문 한국어판과 같은 형식(EPUB)으로, MemtestG80의 실제 소스 코드를 1차 자료로 삼아 새로 집필한 것입니다. 모든 코드 인용은 현재 저장소의 파일:줄번호 기준입니다.
