```c
// memtestG80_cli.cu:185 — 한 iteration의 구조 (일부)
for (uint i = 0; i < maxIters; i++) {
    tester.gpuMovingInversionsOnesZeros(errorCount);          // #2
    for (uint shift=0; shift<8;  shift++) tester.gpuWalking8BitM86(iterErrors, shift);   // #3
    for (uint shift=0; shift<8;  shift++) tester.gpuWalking8Bit(iterErrors, false, shift);

```

## Exercise 2 — Walking 패턴을 손으로 검증

**① 목표**: 비트 연산으로 패턴을 만드는 과정을 직접 따라간다.

**② 코드**: `gpuWalking8BitM86`(core.cu:392)의 패턴 생성부를 읽습니다.

```c
    shift &= 0x7;
    uint pattern = 1 << shift;
    pattern = pattern | (pattern<<8) | (pattern<<16) | (pattern<<24);
```

`shift=0,1,3`에 대해 `pattern`을 **손으로** 16진수로 계산해 종이에 적으세요.

**③ 실행** (검증): 임시로 출력을 추가합니다.
```c
    pattern = pattern | (pattern<<8) | (pattern<<16) | (pattern<<24);
    printf("[HOST] shift=%u pattern=0x%08X\n", shift, pattern);   // 추가
```
```bash
make -f Makefiles/Makefile.linux64
./memtestG80 8 1 2>&1 | grep pattern | head
```

**④ 관찰**: 손 계산과 출력이 일치하나요? (shift=0 → `0x01010101`, shift=3 → `0x08080808`.)

**⑤ 생각해보기**: 왜 8비트 패턴을 32비트 워드 전체로 복제할까요? (모든 바이트 레인을 동일하게 자극.)

> **끝나면 원복**: 추가한 `printf`를 지우세요.

## Exercise 4 — 대역폭 측정의 함정

**① 목표**: 비동기 memcpy를 동기화 없이 재면 왜 엉터리인지 본다.

**② 코드**: `gpuMemoryBandwidth`(core.cu:168)에서 `cudaThreadSynchronize()`를 **잠깐** 주석 처리합니다.

```c
    for (uint i = 0; i < iters; i++)
        cudaMemcpy(dst,src,((size_t) mbToTest)*1048576,cudaMemcpyDeviceToDevice);
    // cudaThreadSynchronize();          // Exercise 4: 일부러 제거
    uint end = getTimeMilliseconds();
```

**③ 실행**:
```bash
make -f Makefiles/Makefile.linux64
./memtestG80 128 1 2>&1 | grep bandwidth
```

**④ 관찰**: 측정된 대역폭이 비현실적으로 **크게**(또는 이상하게) 나오나요? 복사가 아직 안 끝났는데 시간을 재서 그렇습니다.

**⑤ 생각해보기**: D2D memcpy가 비동기라는 것은 무슨 뜻인가요? 대역폭 공식에 왜 `×2`가 붙나요(읽기+쓰기)?

> **반드시 원복**: `cudaThreadSynchronize()`를 되살리세요.
